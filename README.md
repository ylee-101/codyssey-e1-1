## 프로젝트 개요

**팀원 누구나 같은 방식으로 실행, 배포, 디버깅할 수 있는 환경 구성을 목표로 합니다. 같은 서비스를 여러 번 실행해도 재현되는 환경을 만드는 사고방식을 경험하는 것이 목표. 핵심 도구인 리눅스 CLI(터미널), Docker(컨테이너), Git/GitHub(버전 관리 및 협업)를 함께 사용**


- 터미널로 작업 디렉토리와 권한을 정리
- Docker를 설치 및 점검
- 컨테이너를 실행/관리
- 간단한 웹 서버를 Dockerfile로 컨테이너화
- 포트 매핑으로 접속을 확인
- 바인드 마운트/볼륨으로 "변경 반영"과 "데이터 영속성"을 직접 검증
